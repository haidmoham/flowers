# Flowers

A self-drawing watercolor lily bouquet made with p5.js.

## Run locally

From this directory:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

No install or build step is required.

## Astral Flowers

The separate artwork in [`astral/`](astral/) reveals clusters of fragile,
translucent flowers on ivory. The original p5.js piece remains at the root.

With the same local server, open `http://127.0.0.1:4173/astral/`.
The Vercel project deploys only the `astral/` directory.

Material and composition studies remain in `studies/`. They are not deployed.

The [current direction](docs/next-study.md) links the reference analysis and
visual and technical research.
